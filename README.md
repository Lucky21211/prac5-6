## 🛒 Описание
Это учебный интернет-магазин с админ-панелью, реализованный на Node.js, WebSockets и чистом HTML/JS.  
Система состоит из:
- Фронтенда магазина для покупателей (`frontend`)
- Фронтенда админки (`frontend-admin`)
- Двух backend-серверов (`shop-backend` и `admin-backend`)
- REST API, GraphQL API и WebSocket-чата
