## 🛒 Описание
Это учебный интернет-магазин с админ-панелью, реализованный на Node.js, Docker и WebSockets.  
Система состоит из:
- Магазина для покупателей (`frontend`)
- Админки для управления товарами (`frontend-admin`)
- Двух backend-серверов (`shop-backend` и `admin-backend`)
- Графа, REST API и поддержки WebSocket-чата
